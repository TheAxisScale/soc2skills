# Build specs (we build in the open)

These are the complete, test-driven specifications each skill in this kit was built
from — published on purpose. An honesty-first project shouldn't hide how it works.

Each plan is a step-by-step, red-green-refactor build: the failing test, the exact
code, the command to prove it passes, and a commit. Read them to:

- **Understand** exactly how a skill decides what it decides (the logic is in the tests).
- **Audit** our claims — every rule here is backed by a test you can run.
- **Build your own** honest compliance skill using the same pattern.

They're grounded in the principles in [`../DESIGN-PRINCIPLES.md`](../DESIGN-PRINCIPLES.md).
